# External input data

Input datasets are not stored in Git.

- Set `TRENDY_INPUT_DIR` to the TRENDYv10 `downloads/` directory.
- Set `CABON_DATA_DIR` to the directory containing:
  `Cabonetal_site_info.csv`, `rw_onsite.csv`, and `flux_onsite.csv`.

See the repository README for commands and expected NetCDF naming.
